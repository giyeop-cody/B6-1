# ISSUE-002: AWS 계정이 없어 실제 배포를 검증할 수 없다

- 상태: 계정 사용 가능 확인, 보안 설정·배포 준비 대기
- 발견일: 2026-08-15
- 상태 갱신일: 2026-08-17
- 우선순위: 높음

## 현상

처음에는 사용할 AWS 계정이 확인되지 않아 EC2·VPC 생성, 외부 URL, 콘솔 스크린샷, Billing 확인을 수행할 수 없었다. 2026-08-17에 계정 소유자가 기존 계정 사용 가능과 단기 비용 가능성을 확인했다. 다만 루트·IAM MFA, 최소권한 정책, 크레딧·Budget, 서울 리전 Key Pair는 실제 화면에서 아직 확인하지 않았다.

## 원인

과금과 보안에 영향을 주는 외부 계정이므로 구현자가 임의로 만들거나 자격 증명을 대신 다룰 수 없다.

## 안전한 해결 절차

1. 사용자가 AWS 공식 사이트에서 직접 계정을 만든다.
2. 루트 계정에 MFA를 설정한다.
3. 루트로 실습하지 않고 별도 IAM 사용자를 만든다.
4. Free Plan/크레딧/만료일과 예산 알림을 확인한다.
5. Access Key, 비밀번호, `.pem` 파일을 채팅이나 Git에 올리지 않는다.
6. 준비 완료 후 CloudFormation 배포를 진행한다.

## 완료 조건

- [x] 기존 AWS 계정 사용 가능 확인 (계정 소유자 응답)
- [ ] 루트 MFA 완료
- [ ] 별도 IAM 사용자 로그인 완료
- [ ] 서울 리전 선택 확인
- [ ] Credits와 예산 알림 확인
- [ ] Git에 비밀정보가 없음을 확인
