## 🎯 프로젝트 개요

AWS 프리 티어를 사용해서 만든 웹사이트를 인터넷에 배포합니다. VPC, EC2, RDS, Route 53, ALB 등 AWS 핵심 서비스를 구성하고 클라우드 인프라를 경험합니다.

## 🎓 학습 목표

이 과제를 완료한 뒤, 다음을 설명할 수 있어야 한다:

1. AWS VPC/서브넷/보안그룹의 네트워크 구성을 설명할 수 있다
2. EC2에 웹 애플리케이션을 배포할 수 있다
3. IAM 사용자/Role로 안전하게 콘솔에 접근할 수 있다
4. 프리 티어 범위 내에서 비용을 관리할 수 있다
5. 클라우드 인프라의 기본 구성 요소를 설명할 수 있다

## ⚠️ 제약 사항

- 프리 티어 범위 내에서 진행
- 루트 계정 사용 금지, IAM 사용자/Role로만 접근
- 실습 종료 후 리소스 종료/삭제 (과금 방지)
- 모든 리소스는 서울 리전(ap-northeast-2)에 생성
